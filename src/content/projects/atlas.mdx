groups: [cnb]

---

Atlas gives people working with spreadsheets and other data files a way to specify what they want back. They can name the fields in the output and choose their types rather than leaving the processor to guess what a finished record should look like.

I built the web application for setting up and tracking those jobs. For a new layout, a user can ask for suggested fields based on a preview of the file, then edit the proposal before starting the job. When the next file follows a familiar layout, the user can select an existing configuration instead of describing the same fields again.
